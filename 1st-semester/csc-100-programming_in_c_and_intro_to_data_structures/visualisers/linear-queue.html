💡 The Circular Queue Solution

In a standard Linear Queue, insertion condition is simply rear == capacity - 1. Once REAR hits index 3, it cannot move forward!

A Circular Queue solves this by connecting the last position back to the first using modulo arithmetic: rear = (rear + 1) % capacity This allows new elements to reuse vacant spaces at indices 0 and 1!
